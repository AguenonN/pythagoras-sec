Un moteur de décision pour agents MCP

Un agent LLM appelle des outils externes via MCP. Par défaut, il fait confiance à un serveur sur la foi d'une ligne de configuration écrite une fois et jamais revérifiée. Ce dépôt remplace cette confiance par deux choses : une preuve cryptographique d'identité, et une décision journalisée et rejouable sur chaque appel.

Chaque brique ci-dessous est un paquet Go réel. Les liens entre elles sont les imports réels extraits du code, pas un schéma dessiné à la main : les colonnes vont des fondations (aucune dépendance) vers les consommateurs.
